### 🛡️ CyberText Shield — AI Scam / Phishing SMS Detection

Detects smishing (SMS phishing) using a **Hypergraph Neural Network** trained in PyTorch, with a Python backend that serves real-time predictions and persists results.

- **92% accuracy** on a dataset of **1,591 labeled SMS messages**; **89% precision / 90% recall** on the phishing class
- Feature pipeline built on TF-IDF and message metadata; benchmarked against rule-based and CNN-LSTM baselines
- Deployed on Render · **Published and presented at ICCP 2026** (team project)

`Python` `PyTorch` `Graph Neural Networks` `scikit-learn` `NLP` `React Native`

🔗 [Source code](https://github.com/Sagar-A-M/CyberTextShield-Deployed)
